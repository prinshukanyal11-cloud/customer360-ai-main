Synthetic data files for the Customer360 AI demo.

- `customers.csv` — 500 synthetic customer profiles
- `transactions.csv` — ~2,600 synthetic transactions

## IMPORTANT

These are **synthetic/demo data** generated by `scripts/generate_sample_data.py`.
They are intentionally realistic in structure but not real business data.
The application clearly labels demo results as synthetic whenever it loads them.

Regenerate with different dimensions:

```bash
python scripts/generate_sample_data.py --customers 1000 --seed 7
```
